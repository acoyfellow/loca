# Loca gateway quality snapshot — 2026-06-16

This is an exploratory smoke-quality comparison, not a benchmark claim.

## Setup

- Runtime: Cloudflare Workers AI through named AI Gateway `default`
- Dataset: `loca-quality` (10 prompts)
- Judge: `@cf/meta/llama-3.3-70b-instruct-fp8-fast`
- Parallelism: 3 model workers
- Candidate generation: low/disabled hidden reasoning where supported
- Local model weights downloaded: **none**

## Useful misses

- Llama 4 Scout failed strict JSON formatting.
- Gemma 4 and QwQ attempted to reason toward current weather instead of cleanly requiring a live tool.
- Qwen3 fabricated a current NYC temperature in the full run.
- Qwen Coder performed well on implementation/SQL prompts but poorly on general reasoning, tool awareness, and exact formatting.
- Qwen3's RoPE explanation was judged partially complete.

## Interpretation

The top three tying at 1.000 mainly shows that this dataset and single judge are too easy/lenient to separate frontier candidates. It does **not** establish equivalence.

Before choosing weights to download, add:

1. harder code execution cases,
2. adversarial factuality questions,
3. pairwise blind judging,
4. a second independent judge,
5. latency, token usage, and estimated cost,
6. at least one human review pass.
